## 1. 结论先行

1. 现在"太白、卡片也白、轮廓太细"**不是审美口味问题，是三个可以被量化的缺陷**：
   画布与卡片**同为纯白（台阶 1.00:1）**、卡片描边只有 **1.14:1**（远低于"能被看见"的阈值）、
   输入框描边 **1.54:1**（同样看不见）。见 §2 实测表。
2. 更深一层的根因：**浅色主题是冷灰系（`#FFFFFF`/`#F7F8FA`/`#1C1C1E`），深色主题是暖炭系
   （`#171819`/`#202122`/`#F0EDE8`）—— 两个主题根本不在同一个色彩家族里。**
   所以不管单独调哪一项，两个主题都不会像同一个产品。
3. 而项目**已经有一套官方品牌色**（`goodluck-logo-design.md`：炭黑 `#242320`、杏橙 `#ED945F`、
   暖白 `#FAF7F0`，"温暖秩序"），**小程序 UI 一处都没用上**。方案 V2 就是把这套品牌色接回来。
4. 新方向一句话：**浅色用「暖纸」（暖砂画布 + 品牌暖白卡片 + 纯白浮层），深色用「暖炭」
   （暖黑画布 + 暖褐卡片 + 暖白文字）**；同一套色相骨架，只换明度台阶。
5. **不改任何功能、不改信息架构、不改尺寸与文案** —— 只换颜色与"卡片轮廓的表达方式"。

## 2. 诊断：实测数据（这是整份方案的依据）

用 sRGB 相对亮度实算（`_dev_tools/check_palette_contrast.py`）：

| 配对（看的其实是同一件事）              | 现状 V1     | 意味着什么                     |
| -------------------------- | --------- | ------------------------- |
| 画布 vs 卡片 的明度台阶            | **1.00:1** | 完全一样。**白色卡片放在白色画布上，等于没有卡片** |
| 卡片描边 vs 卡片底               | **1.14:1** | 低于人眼可辨阈值 —— 这就是你说的"轮廓太细"  |
| 输入框描边 vs 输入框底             | **1.54:1** | 同样几乎看不见                   |
| 浮层（抽屉）vs 卡片 的台阶           | **1.00:1** | 抽屉与卡片同色，弹出时只剩遮罩在区分        |
| 辅助文字 vs 卡片                 | 3.13:1    | 不达标（已由 V1 修正到 4.81，V2 继续） |

> 判读参考：明度台阶 **≥1.08** 才能稳定看出"两个面"；控件边界要 **≥3:1** 才算"明确的边界"。
> 现状的 1.00 与 1.14，是两个几乎为零的数。

**根因归纳：**

| # | 根因 | 后果 |
|---|---|---|
| ① | 画布、卡片、浮层**三级台面全是同一个白** | 所有内容糊成一片，只能靠描边和间距硬切 |
| ② | 轮廓交给了一条 1.14:1 的细线（2rpx `#EEF0F3`） | 线看不见；想加粗又会让页面变"框框套框框" |
| ③ | 浅色冷灰系 vs 深色暖炭系，**两个色彩家族** | 切主题像换了个 App；品牌气质断裂 |
| ④ | 唯一有彩度的只剩小面积黄/红/蓝/绿点缀 | 整屏是"灰白 + 几个亮点"，没有氛围 |

## 3. 设计方向：暖纸 · 暖炭

一句话：**把界面当成纸。** 浅色是暖砂桌面上的三叠暖纸，深色是暖炭背景上的三叠暖褐卡。

四条原则：

1. **画布不再是白。** 画布承担"桌面"，卡片承担"纸"，浮层承担"最上面那张纸"——
   三级台面各有明度，一眼分得开。
2. **层级靠明度台阶 + 柔和投影，不靠描边。** 浅色用双层级投影表达"浮起来"，
   深色用台面明度差表达（这是标准 elevation 模型，不是两套逻辑）。
   描边退回它该干的事：**只标"哪里可以输入 / 点选"**，并且要看得见（≥3:1）。
3. **色彩收敛到品牌三色。** 炭黑（文字与主操作）、暖白（台面）、杏橙（关键节点）。
   杏橙**只出现在关键节点**（选中、焦点、关键状态），不做大面积装饰 —— 这正是品牌文档
   "颜色应保持平涂，精确的面积控制比额外装饰更重要"的原话。
4. **两个主题同族。** 浅色"暖纸" ↔ 深色"暖炭"，同一套色相骨架，只换明度。

## 4. 台面模型（三级纸）

| 层级 | 角色 | 浅色 | 深色 | 台阶 |
|---|---|---|---|---|
| L0 | 画布（桌面） | `#F1ECE2` 暖砂 | `#14110D` 暖黑 | vs L1 = 1.10 / 1.12 |
| L1 | 卡片（纸） | `#FAF7F0` **品牌暖白** | `#211D17` 暖褐 | vs L2 = 1.07 / 1.09 |
| L2 | 浮层（抽屉 / 悬浮导航 / 气泡） | `#FFFFFF` 纯白 | `#2B2620` | — |
| L3 | 凹陷（输入框 / 信息块 / 内嵌面板） | `#EAE3D4` | `#1A1712` | vs L1 = 1.13 / 1.19 |
| — | 按压态 | `#E2DAC8` | `#332D25` | — |

> 纯白 `#FFFFFF` 在 V2 里是**稀缺资源**，只留给"浮在最上面的那一层"。
> 卡片用品牌暖白，画布比它再深一档 —— 这样卡片自己就"亮起来了"，不再需要描边帮忙。

## 7. 组件规范（用颜色说"层级"，不用描边说）

### 7.1 卡片与投影

- **浅色**：卡片为 `--surface-card`（暖白），**去掉 2rpx 描边**，改用双层柔和投影：

  | 层级 | 用途 | 参数 |
  |---|---|---|
  | `--elev-1` | 普通卡片 | `0 1rpx 2rpx rgba(36,35,32,.05), 0 6rpx 20rpx rgba(36,35,32,.06)` |
  | `--elev-2` | 浮层 / 悬浮导航 / 地图气泡 | `0 2rpx 6rpx rgba(36,35,32,.06), 0 16rpx 40rpx rgba(36,35,32,.10)` |

  双层的意义：近处那层压出边缘（让卡片"贴着桌面"），远处那层给出浮起量。单层大模糊会糊。

- **深色**：**不用投影**（深色投影等于看不见），改用台面明度差：
  卡片 `#211D17` 落在画布 `#14110D` 上（1.12:1），浮层再抬到 `#2B2620`。
  这是标准 elevation 模型，**不是两套逻辑**，同一套语义令牌在两种主题下由不同手段实现。

- 圆角维持 40rpx（大卡 48rpx）。

### 7.2 描边的去向（回答"轮廓太细"）

- **卡片的描边取消** —— 轮廓改由"卡片比画布亮"承担。
  （原来的 2rpx `#EEF0F3` 只有 1.14:1，属于"以为有、实际看不见"，是最糟的状态。）
- **`--border-control` 只用于"这里能输入 / 能点选"**：输入框、未选分段、未选号码球、
  未选的次级按钮。它现在是 **`#8A7F69`（3.69:1）** —— 一条线就够，看得见，且不再需要加粗。
- 卡片**内部**的分组线用 `--line-subtle`（`#E3DCCC`，装饰级，不参与可读性）。

### 7.3 主操作与强调色

| 角色 | 浅色 | 深色 | 理由 |
|---|---|---|---|
| 主按钮 | 炭黑 `#242320` + 暖白字 | 杏橙 `#ED945F` + 炭黑字 | 浅色下炭黑＝"清晰和可信赖的基调"；深色下炭黑会消失，必须换成杏橙 |
| 选中态 / 当前项 | 炭黑实底（分段、Tab） | 杏橙软底 `#3A2A1D` + 浅橙字 | 一个页面里"实心强对比"的位置是有限的 |
| 焦点 / 链接 / 关键节点 | 杏橙深档 `#A94D16`（文字态） | 杏橙 `#ED945F` | 杏橙实心做不出 4.5:1，做文字必须用深档 |
| 待兑奖 | 琥珀 `#F0B429` 徽章 + `#FBEAC0` 卡 | `#E8C27A` + `#382D19` | 全站唯一允许大面积暖色块的卡片 |

**亮黄 `#FFD02F` 的去向**：它太"柠檬"，放在暖砂底上会发酸；降级为**琥珀 `#F0B429`**，
只保留"待兑奖/奖励"这一种语义，以及取景器引导线（那里画面永远是暗的，需要它够亮）。

### 7.4 号码与热力图

- 号码红由 `#E63946` 调暖到 `#C93A34`（正红偏朱），蓝由 `#4262FF` 调到 `#2F4FA8`（深靛蓝）。
  原因：`#4262FF` 是电光紫蓝，放在暖纸底上是最扎眼的一处"不搭"。深靛蓝在暖底上更沉稳，
  且球内白字对比度从 4.75 提到 8.6。
- 热力图由中性绿改为**暖绿 5 阶**：L0 是一个暖中性（无购彩），L1→L4 逐级加深加饱和。
  相邻级台阶 ≥1.06，与卡片台阶 ≥1.16 —— 保证在暖底上每一阶都分得开。

### 7.5 底部导航

- 胶囊底 = `--surface-raised`（浅色纯白 / 深色 `#2B2620`）+ `--elev-2` 投影（深色无投影）。
- 选中项 = 炭黑胶囊（浅色）/ 杏橙软底（深色）；未选文字与图标 = `--text-muted`。
- 底板渐变（毛玻璃兜底）由画布色系生成：浅色 `rgba(241,236,226,0→.78→.94)`，
  深色 `rgba(20,17,13,0→.78→.94)` —— 三档同色系，避免渐变色偏。
