# 火山引擎配置指南

> 彩票小助手后端三处能力依赖火山引擎：
> 1. **开奖结果查询** → `SearchInfinity`（豆包搜索，联网搜索 API）
> 2. **彩票 OCR** → `deepseek-v4-1-flash-261017`（多模态视觉理解，2026-10-27 起统一）
> 3. **号码推荐** → `doubao-seed-2-1-pro-260628`（方舟文本大模型）
>
> 全程只需 **2 个 API Key + 1 个推理接入点 ID**，都在火山引擎控制台（`console.volcengine.com`）获取，5 分钟可完成。

---

## 0. 配置前确认

- 已有火山引擎账号（未实名认证需先完成**实名认证**，方舟模型开通要求）
- 浏览器登录 `https://console.volcengine.com`

> ⚠️ **OCR 模型变更提醒（2026-10 更新）**：
> - `Doubao-1.5-vision-pro` 已于 **2026-03-31 正式下线**（LAS 算子下线公告）
> - `doubao-seed-1.6-vision` 亦将下线，**不要再用**
> - 当前默认 **`deepseek-v4-1-flash-261017`**（2026-10-27 统一；实测支持图片输入 + json_object），备选 `doubao-seed-2.0-lite` / `doubao-seed-2.0-mini`

## 1. 开奖查询：SearchInfinity（豆包搜索）

### 1.1 开通

1. 打开 `https://console.volcengine.com/search-infinity/web-search-exp`
2. 阅读并同意服务协议，点击**开通服务**
3. 免费额度：**每月 500 次搜索调用**（本项目按彩种每周 6 期 × 4 周 = 24 次/月，绰绰有余）

### 1.2 获取 API Key

- 在该控制台页面（或左侧"API Key 管理"）创建 API Key，复制保存
- 形如 `xxxx-xxxx-xxxx-xxxx`（以页面实际为准）

### 1.3 配置到 `.env`

```env
VOLC_SEARCH_API_KEY=你的豆包搜索APIKey
```

> 端点：`https://torchlight.byteintlapi.com/search_api/web_search`（代码已内置，无需配置）

## 2. 火山方舟（OCR 视觉模型 + 号码推荐 LLM）

两个能力共用**同一个方舟 API Key**，但推荐 LLM 额外需要一个**推理接入点 ID**。

### 2.1 进入方舟控制台

打开 `https://console.volcengine.com/ark`（默认北京地域）。

### 2.2 创建 API Key

1. 右上角头像 → **API Key 管理**（或左侧菜单"API Key 管理"）
2. 点击 **创建 API Key** → 复制保存（形如 `xxxxxxxx-xxxx-xxxx-xxxx`）
3. ⚠️ Key 只在创建时完整显示一次，请立即保存

### 2.3 创建推理接入点（号码推荐 LLM 用）

1. 左侧菜单 **在线推理 → 推理接入点**
2. 点击 **创建推理接入点**
3. 在模型列表中选择：**Doubao-Seed 系列 → `doubao-seed-2-1-pro-260628`**
   - 若未显示，先到「开通管理」开通该模型（需实名认证）
4. 按需设置（单机个人用默认即可）：
   - 实例数：1
   - 并发上限 / 速率：默认
5. 创建完成后，在接入点列表复制 **接入点 ID**（形如 `ep-20260819xxxxx-xxxxx`）

### 2.4 OCR 视觉模型说明

- OCR 默认用 **`deepseek-v4-1-flash-261017`**（2026-10-27 统一；实测支持 `image_url` 图片输入 + `json_object` + `thinking:disabled`），备选 `doubao-seed-2.0-lite` / `doubao-seed-2.0-mini`
- ⚠️ 方舟统一校验：`response_format={'type':'json_object'}` 要求 **prompt 中出现 `json` 字样**，否则 400 `InvalidParameter`。`OCR_PROMPT` 自带 `JSON`，改写 prompt 时别删掉
- 代码优先读 `ARK_VISION_MODEL`，未填时默认 `deepseek-v4-1-flash-261017`
- 若直调报「模型不存在 / Model not found / 未开通」：
  1. 方舟控制台 → **开通管理** → 确认已开通该模型；或
  2. 到「在线推理 → 推理接入点」为该模型创建接入点，把 **`ep-xxx`** 填入 `ARK_VISION_MODEL`（代码支持 ep- 接入点直填）

### 2.5 配置到 `.env`

```env
ARK_API_KEY=你的方舟APIKey
ARK_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
ARK_VISION_MODEL=deepseek-v4-1-flash-261017
ARK_LLM_ENDPOINT_ID=ep-xxxxxxxxxxxxxxxxxxxxx
ARK_LLM_MODEL=doubao-seed-2-1-pro-260628
```

## 4. 一键验证配置

填好 `.env` 后运行：

```bash
cd goodluck-plus/server
npm run check:volcengine
```

脚本会依次测试：

| 检查项 | 判定 |
|---|---|
| ① 豆包搜索 API Key | 真实发起一次搜索"双色球 开奖号码"，成功返回结果 |
| ② 方舟 LLM（推荐） | 调用 `ARK_LLM_ENDPOINT_ID` 生成一组号码 JSON |
| ③ 方舟 Vision（OCR） | 上传内置测试图调用 `ARK_VISION_MODEL` 识别 |

任一失败会打印具体错误信息（HTTP 状态码 / 错误码），对照第 5 节排查。

## 5. 常见错误排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 开通模型提示需实名认证 | 火山引擎账号未完成实名 | 账号中心完成实名认证 |
| 搜索返回 `401 Unauthorized` | `VOLC_SEARCH_API_KEY` 填错或未开通 | 核对 Key、确认已开通 SearchInfinity |
| LLM 报 `Invalid model` / `Model not found` | `ARK_LLM_ENDPOINT_ID` 不是接入点 ID | 确认填的是 `ep-` 开头 ID（不是模型名） |
| 报 `Model not opened` | 模型未开通 | 方舟「开通管理」开通 `doubao-seed-2-1-pro-260628` |
| 报 `Access denied` / `Authentication` | `ARK_API_KEY` 错误 | 重新创建 Key，注意别带多余空格 |
| OCR 报「模型不存在/已下线」 | 仍填了 `doubao-1.5-vision-pro` 或 `doubao-seed-1.6-vision`（均已/将下线） | 改为 `deepseek-v4-1-flash-261017`（当前默认）或 `doubao-seed-2.0-lite`，或建推理接入点填 `ep-xxx` |
| OCR 报错但 Key 正确 | 视觉模型未开通或 ID 带日期后缀不可用 | 「开通管理」开通；或为该视觉模型创建推理接入点填 `ep-xxx` |
| 一切正常但开奖仍无数据 | 开奖同步只在开奖日晚 21:00-23:00 触发 | 临时手动触发：删除对应期 `draw_results` 后重启服务，或等待 cron |

## 6. 安全提醒

- **Key 只写在 `.env`**，`.gitignore` 已忽略 `.env`，切勿提交到仓库
- 不在日志、代码注释、聊天记录中明文粘贴完整 Key
- 每月可在方舟「用量统计」与 SearchInfinity 控制台查看配额消耗
- 若 Key 泄露，立即在控制台删除并重建，同步更新 `.env`
